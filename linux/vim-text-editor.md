# Most usefull vim Cheatsheet 
INSERT / EDIT
i       → start typing
Esc     → return to Normal mode

MOVE
h       → left
j       → down
k       → up
l       → right

EDIT
d      -> delete entire selected text
x       → delete character
dd      → delete line
yy      → copy (yank) line
p       → paste
u       → undo
Ctrl+r  → redo

SEARCH
/word   → search for "word"
n       → next match
N       → previous match

SAVE / EXIT
:w      → save
:q      → quit
:wq     → save + quit
:q!     → quit without saving


#              → main topic

##             → command/topic

`command`      → inline command

```bash ...``` → Linux commands + syntax highlighting

```text ...``` → Vim shortcuts / key combinations

> ⚠️           → warning

---            → separate sections
